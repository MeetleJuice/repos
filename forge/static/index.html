        How to update or restore
        
          
          Use the Update button in the top bar for managed releases. The
          original downloaded folder remains the launcher and fallback. Updates
          back up projects and keep installed versions separate.
        
          
        
          
          Stop Foundry in its terminal before switching versions. Extract the
          new program ZIP into a new folder and start its launcher. On Windows,
          this version stores projects in Local AppData and copies missing
          projects from a legacy data folder beside the program, keeping
          originals.
        
          
        
          
          To restore a workspace backup: stop Foundry, keep a copy of the
          current data folder, then extract the backup’s projects folder into
          that data folder. The backup excludes API keys; keep your .env
          separately.

          Your model connections
          
        
      
          
      
          
        Ollama runs on your computer. Optional API keys belong in your local
        .env file; restart the workbench after editing it.
      
          
      
          
        
          Automatic model studio
          
        
        
          Use your imported keys and installed Ollama models. Foundry discovers model IDs and builds separate planner and builder routes, including alternate models. Applies to new projects and the open idle project. No generation runs until you grant cloud consent. Paid models may incur charges. Missing provider setup is skipped.
          
        
          
          Choose your Desktop .env file (a Notepad .env.txt also works). It is
          copied to your private Foundry workspace on this computer. Key values
          are never shown or saved in projects.
        
          
        
        
        
          
        
        
        
          
          Checks read model catalogues using your keys. They do not send project
          content or prove generation quota. Choose models below, then apply the
          cloud route. Generation can incur API charges.
        
          
        
          
          Arrange provider cards with Earlier / Later; the first selected model
          is primary. Skipped providers receive no requests. Service, timeout
          and invalid-JSON failures move to the next configured provider without
          sleeping. A hanging request must time out first. Truncation gets
          bounded same-model recovery and never falls back to a smaller output
          ceiling. Planner output reserves at least 8192 text tokens plus
          supported thinking; compact planning can reduce an estimate without
          dropping requirements or lowering your floor. Per-provider socket
          timeouts are not an absolute whole-job deadline.
        
          
        
          
          Cloudflare Workers AI needs both CLOUDFLARE_API_TOKEN and
          CLOUDFLARE_ACCOUNT_ID in your local .env. A global Cloudflare API key
          is not a Workers AI bearer token. Hugging Face accepts HF_TOKEN.
          Missing setup does not block other providers. Import the Desktop file
          again after edits.
        
          
        
          Advanced model choices and manual routing
        
          
        
        
        
          
          Local fallback runs on your computer and may be slower or less
          capable. It is used only when explicitly selected. Changing routes
          preserves saved files and resumes unfinished tasks. Applying a route
          does not grant cloud consent.
