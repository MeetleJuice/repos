        Your workspace
        This folder holds your projects. Program updates do not need to replace it. Keep a backup before any update.
        How to update or restore
        Stop Foundry in its terminal before switching versions. Extract the new program ZIP into a new folder and start its launcher. On Windows, this version stores projects in Local AppData and copies missing projects from a legacy data folder beside the program, keeping originals.
        To restore a workspace backup: stop Foundry, keep a copy of the current data folder, then extract the backup’s projects folder into that data folder. The backup excludes API keys; keep your .env separately.
