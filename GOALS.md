# Idea Foundry goals

Foundry is a local-first, bounded app-building harness for small Python-served browser applications. It turns an idea into a reviewed proposal, freezes approval, applies sequential scoped tasks, inspects source, optionally executes approved checks and repairs, and exports source-bound evidence.

The controller owns approval, file scope, budgets, evidence and updates. Models propose content; they cannot grant themselves execution permission or mark an app verified. Installed models and successful catalogue requests do not prove project capability or quota.

The 0.25 update adds another local runtime, explicit completion gates, repeated-call protection, optional local streaming, and clearer model/update controls. Existing project directories, frozen checks and backups remain compatible. Universal app completion, measured GPU fitness, unrestricted tool execution and automatic source promotion are not goals.
